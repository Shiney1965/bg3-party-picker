# Third-Party Notices — Party Picker

Party Picker's own code and documentation are released under the MIT License (see `LICENSE`). This file lists material that Party Picker depends on but does **not** own.

## BG3 Script Extender — required dependency (not included)

Party Picker requires the **BG3 Script Extender** by [Norbyte](https://github.com/Norbyte/bg3se) to run. The Script Extender is **not bundled** with Party Picker; users install it themselves. All rights remain with its author.

## Mod Configuration Menu (BG3MCM) — required dependency (not included)

Party Picker requires **Mod Configuration Menu** by AtilioA and contributors (NexusMods mod 9162) for its Party tab and settings. MCM is **not bundled** with Party Picker; users install it themselves. Party Picker ships an MCM *blueprint* (a JSON description of its own settings, authored by Party Picker's author) that MCM reads; it contains no MCM code. All rights to MCM remain with its authors.

## Larian Studios — Baldur's Gate 3

Party Picker is an unofficial, fan-made modification for Baldur's Gate 3 and is not affiliated with or endorsed by Larian Studios. Party Picker ships **no Larian game files**, modified or otherwise: it contains only its own Script Extender Lua, its MCM blueprint and its mod metadata. At runtime it calls the game's own story procedures through the Script Extender and adds rows to two of the game's story tables; it never alters the game's data files. All rights to Baldur's Gate 3 remain with Larian Studios.

## Summary

Party Picker bundles no third-party binaries, tools or game files. Its two required dependencies, the Script Extender and Mod Configuration Menu, are installed separately by the user.
